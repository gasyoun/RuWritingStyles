## What was wrong earlier

PR #220's position-swap probe compared judge C (`glm-5.3-flash`, reversed order)
against rater B (`claude-fable-5`, original order). Judge model AND candidate
order changed together, so the observed 0/25 flips could not identify a
position-only effect — verified from recorded metadata (`rater_c` / `rater_b`
fields), confound claim confirmed.

## Design (fixed before judging)

Same judge (**GLM 5.3 Flash**, `opencode/z-ai` session lane — H4658's rater C
identity), same frozen 25-run sheet (sha256 `8f92288f…42e62`, unchanged since
11-07-2026), verbatim rater-B rubric, two conditions per item (original vs
reversed+renumbered), identity-blinded presentation (opaque task ids, mapping
hidden until all 50 verdicts recorded), seeded randomized call order
(SEED=5010). No exclusions; `vedic-r02` included.

## Result

| metric | value |
|---|---|
| valid pairs | 25/25 (0 invalid, 0 malformed) |
| successful judgements | **50/50 budget** (0 of 5 redos used) |
| discordant pairs | **0/25** (caught: 0, type_correct: 0, false_positives: 0) |
| flip rate (Wilson-95) | 0.0% **[0.000, 0.133]** |
| first-position preference | not detected (median target pos 1 among all-positive verdicts; 0 negative verdicts to compare) |
| material order sensitivity flag | **false** (threshold ≥0.20 + Wilson lower >0) |

**Zero flips is not proof of no bias**: with 0/25 the Wilson-95 upper bound is
0.133 — order sensitivity up to ~13.3% remains compatible with this data.

**Corrected conclusion:** with only candidate order changed, the judge's
verdicts are in-sample order-invariant on all 25 items. The earlier 0/25 result
therefore does NOT hide a same-judge order effect on this corpus — the
cross-judge comparison (C vs B) is the only place judge sensitivity can live,
and the position-only component is bounded above by ~13.3% (n=25).

Post-hoc stability observation (not preregistered): this session's judgements
reproduce the same judge's own 14-09-2026 swapped-order verdicts (rater C,
PR #220) 25/25 on caught/type_correct and on the FP>0 run set {pseudo-r01,
pseudo-r05, vedic-r01, samasa-r05, commentary-r03} — cross-session stability
under full re-presentation, ~9 days apart.
