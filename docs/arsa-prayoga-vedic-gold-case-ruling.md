## 1. The claim under test

The author's objection, in full: *«язык аршея, то есть язык риши, то есть язык эпоса — и
этим словом узаконены отклонения, например, в Рамаяне, относительно Панини»* — therefore,
possibly, *«часть „анахронизмов“ может быть не ошибкой, а признанной эпической нормой»*.

If that held, the gold case
[examples/input/vedic-classical-anachronism.md](https://github.com/gasyoun/RuWritingStyles/blob/main/examples/input/vedic-classical-anachronism.md)
would be punishing a recognised norm rather than an error, and every detection number
computed on it — including the 24/25 and 25/25 of A29 §4.6 — would be measuring the wrong
thing.

It splits into three questions with different answers:

| Q | Question | Bears on |
|---|---|---|
| Q1 | Does *ārṣa prayoga* run in the **reverse** direction — can it license describing *Vedic* language in *classical/epic* terms? | the verdict already applied |
| Q2 | Does the case's input text contain an **epic**-axis claim distinct from its classical-axis claim? | the rubric |
| Q3 | Should any passport carry an exemption clause of the *ārṣa* shape at all? | the style layer |

## 2. Q1 — ruled: *ārṣa* does not run in reverse

**The planted error stays an error. The 19-07-2026 adjudication stands untouched, and
*ārṣa* never reaches the case's classical-axis claim.** Four independent grounds:

1. **Pāṇini's architecture makes Vedic the *marked* domain, not the derived one.** The
   Aṣṭādhyāyī's default object is the *bhāṣā*; Vedic material enters only under explicit
   domain markers (`chandasi`, `mantre`, `nigame`, `brāhmaṇe`) plus open variation rules —
   `bahulaṃ chandasi`, `chandasi śāyaj api` (3.1.84), `vyatyayo bahulam` (3.1.85). Rules run
   classical → *extended to* → Vedic. Nothing projects classical norms back onto the Veda as
   a standard the Veda must meet (Bronkhorst,
   [*Pāṇini and the Veda reconsidered*](https://www.researchgate.net/publication/263470324_Panini_and_the_Veda_reconsidered)).
2. **The tradition's one explicit rule about direction is a PROHIBITION, and it runs the
   other way.** The Mahābhāṣya cites `chandovat kavayaḥ kurvanti` ("poets do as in the Veda")
   and rejects it — `na hy eṣā iṣṭiḥ`: such Vedicizing in non-Vedic language is a *doṣa*
   (Kawamura, *JIBS* 65.3 (2017): 1059–1065). If the tradition refuses even
   Vedic→classical transfer, it a fortiori licenses no classical→Vedic one.
3. **The categories do not exist to be applied.** The Ṛgveda has a productive subjunctive
   (*leṭ*), an injunctive, a large infinitive inventory and a living aorist with distinct
   functions — lost or vestigial in classical Sanskrit (Whitney, *Sanskrit Grammar*,
   chs. VIII, XI). Calling an RV form a "classical aorist" names a category the classical
   language does not possess in that function: a **category error, not a liberty**.
4. **Even the boldest traditional Veda→epic reader stops short of this.** Nīlakaṇṭha
   Caturdhara (*Mantrarāmāyaṇa*, *Mantrabhāgavata*, Harivaṃśa commentary) reads epic
   *meaning* into ~60 RV verses — but never claims RV *morphology* follows classical rules
   (Minkowski, Third Dubrovnik Conference, HAZU 2005).

### Corollaries that change how this is written up

- **`ārṣa` in Pāṇini is not this concept at all.** It occurs once, at **A 2.4.58**, as a
  label for a *taddhita* affix class denoting descent from a ṛṣi. In the
  Prātiśākhya/Bhāṣya layer it means the *Saṃhitā* text as against the *padapāṭha*. The
  "exempted despite the rules" sense is a **later commentarial extension**, not a Pāṇinian
  category — so citing "Pāṇini" for the exemption is itself an anachronism of the same
  family the case tests for.
- **Attested instance of the excuse-move, verbatim:** Śrīdhara Svāmin's *Bhāvārthadīpikā*
  on the Bhāgavata glosses `hari-viriñci-hareti saṃjñāḥ` with `sandhiḥ ārṣaḥ` — "the sandhi
  is that of the ṛṣis" (*hara* + *iti* → *hareti*). Verse number (BhP 1.2.23?) unconfirmed;
  the quotation is attested.
- **Where the licence actually comes from, empirically.** Epic deviations are "generally
  considered to be on account of interference from Prakrits, or innovations, and **not**
  because they are pre-Pāṇinian" (Oberlies, *A Grammar of Epic Sanskrit*, de Gruyter 2003 —
  via reviews; the book's own pages could not be fetched). So the operative licence is
  **epic-specific** (metri causa, Middle-Indic contact), while the tradition's own rationale
  is authority dressed as archaism. Any future passport clause must not claim these
  deviations are archaisms.

**`R2607-05` therefore resolves `refuted`** for the case as applied.

## 3. Q2 — the real defect, and it never depended on *ārṣa*

The objection was wrong about *ārṣa* and right that something was wrong with the case. The
input text plants the period-collapse **twice**, on two poles:

- **Classical pole** — RV X.129 obeys Pāṇini; "classical aorist"; mature-Sanskrit sandhi.
- **Epic pole** — accent set «по нормам эпического языка»; the verse analysable like a
  Mahābhārata verse.

The rubric's `purpose` named only the classical pole, while the graded model findings lean
at least as hard on the epic one — the representative run text in
[evals/annotation/sheet-h073gov.json](https://github.com/gasyoun/RuWritingStyles/blob/main/evals/annotation/sheet-h073gov.json)
argues «в эпическом санскрите ударение утрачено» and «Махабхарата написана на эпическом
санскрите, который значительно моложе…». Runs were being credited under a rubric that did
not describe what they caught.

Note in passing that the epic-pole claim is **doubly** false: epic Sanskrit has no recorded
accent at all, so «ударение по нормам эпического языка» describes a norm that does not
exist.

### What was repaired

**The rubric now names both poles.** `purpose` for `vedic-classical-anachronism` in
[evals/manifest.json](https://github.com/gasyoun/RuWritingStyles/blob/main/evals/manifest.json)
states the two poles explicitly, states that they are **one** finding class
(`anachronistic_sanskrit_period` — the canonical label says *period*, never *classical*, and
covers any post-Vedic pole), and states that the aggregate does not record which pole a run
caught. The generalised requirement was added to
[evals/GOLD_PROTOCOL.md](https://github.com/gasyoun/RuWritingStyles/blob/main/evals/GOLD_PROTOCOL.md):
a case's `purpose` must enumerate every planted claim, not just the one that names the case.

### What was deliberately NOT done, and why

| Rejected repair | Why not |
|---|---|
| Narrow the input text to the classical pole | The 25 graded runs behind A29 §4.6/§4.7 and every `gold-annotation-*.json` were scored against **this** text. Editing it silently retargets published numbers at a document that no longer exists. |
| Add a second `required_finding_types` entry for the epic pole | It would need a new type in `checks` of [styles/passports/elizarenkova-veda.yml](https://github.com/gasyoun/RuWritingStyles/blob/main/styles/passports/elizarenkova-veda.yml), i.e. a change to the reviewer's declared vocabulary — the measurement instrument — mid-series, forcing a baseline re-promote for a class the existing canonical type already covers. |
| Extend `accepted_finding_aliases` | Protocol-forbidden (GOLD_PROTOCOL § «Политика меток»), and already rejected once as the `add_alias` option of this very adjudication. |
| Edit the frozen rater sheet's copy of `purpose` | `evals/annotation/sheet-h073gov.json` records what rater B was actually shown in 2026-07. It is audit trail; it keeps the old wording by design. |

## 4. Q3 — gated, not applied

Whether an epic-facing passport (e.g.
[styles/passports/smirnov-mahabharata.yml](https://github.com/gasyoun/RuWritingStyles/blob/main/styles/passports/smirnov-mahabharata.yml))
should carry a Novgorod-shaped clause — *не считать отклонение от паниниевской нормы ошибкой
в эпическом тексте без проверки*, on the model of the existing
[styles/passports/zalizniak-novgorod.yml](https://github.com/gasyoun/RuWritingStyles/blob/main/styles/passports/zalizniak-novgorod.yml)
line «не должен считать отклонение от книжной нормы ошибкой без проверки» — is a
**style-layer change with eval consequences**, and is not applied here.

Three things a human needs before ruling on it:

1. Such a clause must **not** be attached to `elizarenkova-veda`. That passport reviews
   *Vedic* text; §2 establishes the licence does not reach Vedic material, so a clause there
   would license exactly the error the gold case plants.
2. If written for an epic passport, the clause must say the licence is epic-specific
   (metri causa / Middle-Indic contact), never that the deviations are archaisms — §2's
   Oberlies corollary.
3. Adding a `limits` line changes the review prompt, so it needs a baseline re-promote and
   makes post-change runs non-comparable to the A29 tables.

Empirical instrument for grounding such a clause in named commentator instances: H1324
(Opus 4.8) — MBh/Rāmāyaṇa commentary parsing feasibility,
[handoffs/H1324](https://github.com/gasyoun/Uprava/blob/main/handoffs/H1324-Opus_CommentaryStrategies_mbh-ramayana-commentary-parsing-feasibility_19.07.26.md).

## 5. Not verified — do not report these as settled

- The exact Mahābhāṣya locus of `chandovat kavayaḥ kurvanti | na hy eṣā iṣṭiḥ` (known via
  Kawamura 2017; PDFs returned 403).
- Any named MBh verse where Nīlakaṇṭha writes *ārṣa* — his commentary is not searchable text.
- Any named Rām verse where Govindarāja or Maheśvaratīrtha writes *ārṣa*.
- Oberlies' own pages on *ārṣa* (the claim rests on review summaries).
- The verse number of the Śrīdhara `sandhiḥ ārṣaḥ` gloss.

## 6. Effect on published numbers

None of A29's numbers move. The mechanical layer stays 24/25 = 0.96 and the substantive
layer 25/25 = 1.00; the input, the scoring block and the aliases are unchanged, so the
scored quantity is identical. What changed is that the rubric now describes what the text
actually plants, and §5 of
[docs/methodology-paper-draft.ru.md](https://github.com/gasyoun/RuWritingStyles/blob/main/docs/methodology-paper-draft.ru.md)
now states plainly that the case bundles two period-poles and that the reported detection
number does not distinguish which one a run caught.
