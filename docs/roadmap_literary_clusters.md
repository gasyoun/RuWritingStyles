## Предисловие: Почему литературоведение сложнее лингвистики для pipeline

Лингвистика имеет внутреннюю логику: либо грамматично, либо нет; либо датировка подтверждена, либо нет. Литературоведение — дисциплина, где **интерпретация является результатом, а не методологическим дефектом**. Это означает:

1. Больше кластеров с высоким `interpretation_tolerance`, что затрудняет eval.
2. Нет эквивалента «этимологически неверно» — есть «интерпретация слабо обоснована».
3. Жанровое разнообразие шире: от текстологии (близко к ИЭШ) до эссе (близко к публицистике).
4. Авторский голос в литературоведении сильнее, чем в лингвистике — его потеря при правке ощутимее.

Pipeline должен по умолчанию работать в режиме `comments_only` для всех литературоведческих текстов. Revision — только при явном запросе автора.

## Часть I. Девять литературоведческих кластеров

### Кластер L1: Формальная школа / ОПОЯЗ

**Ключевые фигуры:** Шкловский, Эйхенбаум, Тынянов, Якобсон (ранний)  
**Временной диапазон:** 1910–1930-е, влияние на структурализм до 1970-х  
**Эпоха по philology.ru:** Обильно представлена через переиздания и исследования о школе

**Стилистические маркеры:**
- Строгое разграничение «приема» и «материала» — терминологическая пара неприкосновенна
- «Остранение» — авторский термин Шкловского; не переводить, не перефразировать
- Аналитическая интонация без психологизма: не «автор хотел», а «текст делает»
- Синтаксически компактно; короткие утверждения, затем иллюстрация
- Антириторика: намеренный отказ от «красивых» метафор в аналитической части

**Норма неопределенности:** низкая. Формалисты предпочитают сильные утверждения.

**Конфликты:** Прямо конфликтует с L6 (Бахтин): формалисты — антидиалогисты.

```yaml
id: cluster:lit_opoyaz
name: "Формальная школа / ОПОЯЗ"
markers:
  lexical:
    - "прием"
    - "остранение"
    - "автоматизация / деавтоматизация"
    - "конструктивный принцип"
    - "доминанта"
    - "функция"                  # в формальном, а не бытовом смысле
  epistemic:
    - anti_psychologism: true    # избегать «автор думал / хотел / чувствовал»
    - text_immanent_analysis: true
forbidden_edits:
  - Нельзя добавлять психологические объяснения поступков автора
  - Нельзя заменять «прием» на «средство» или «способ»
  - Нельзя убирать «остранение» — это термин, не метафора
conflict_priority:
  vs_lit_bakhtin: escalate      # парадигматический конфликт
  vs_lit_textology: complement
pipeline_risk: medium
```

### Кластер L2: Структурная поэтика / Московско-Тартуский литературоведческий раздел

**Ключевые фигуры:** Лотман, Успенский, Минц, Цивьян  
**Связь с лингвистикой:** Прямое продолжение кластера `cluster:mts`, примененное к художественному тексту  
**Ключевые работы:** Лотман — «Структура художественного текста» (1970), «Анализ поэтического текста» (1972)

**Стилистические маркеры:**
- «Художественный текст как семиотическая система» — базовая метафора
- Строфические / синтаксические / семантические уровни анализируются параллельно и иерархически
- Схемы и таблицы структуры текста — не иллюстрация, а аргумент
- «Художественное пространство», «художественное время» — термины с точными определениями
- Допустимы формульные записи («уровень Х коррелирует с уровнем Y»)

**Норма неопределенности:** средняя. Структуралист оговаривает границы модели.

```yaml
id: cluster:lit_structural
name: "Структурная поэтика / МТШ-литературоведение"
extends: cluster:mts
markers:
  lexical:
    - "структура текста"
    - "уровни текста"
    - "семиотическая система"
    - "художественное пространство / время"
    - "изоморфизм уровней"
  syntactic:
    - parallel_level_analysis: true   # одновременный разбор нескольких уровней
    - schema_as_argument: true
forbidden_edits:
  - Нельзя убирать схемы — они несут смысл
  - Нельзя заменять «художественное время» на просто «время» в тексте
pipeline_risk: medium
```

### Кластер L3: Историко-биографическая и архивная школа

**Ключевые фигуры:** Томашевский (поздний), Гроссман, Долинин, Сурат  
**Аналог в лингвистике:** ИЭШ — наибольшее сходство по риторике

**Стилистические маркеры:**
- Датировка рукописей и писем — с обязательными оговорками
- Атрибуция: «по всей видимости принадлежит», «нет оснований сомневаться в авторстве»
- Архивные шифры (фонд, опись, дело, лист) — неприкосновенны
- Цитаты из рукописей — точные, с указанием разночтений
- Биографический факт не используется как интерпретация сам по себе — только в связке с текстом

**Норма неопределенности:** высокая. Атрибуции — гипотезы до верификации.

**Это кластер с наивысшим риском фактической ошибки при LLM-правке** (аналог ИЭШ).

```yaml
id: cluster:lit_textology
name: "Историко-биографическая и текстологическая школа"
extends: cluster:iesh            # риторика и риски идентичны ИЭШ
markers:
  lexical:
    - "автограф"
    - "беловая / черновая рукопись"
    - "атрибуция"
    - "датировка"
    - "разночтение"
    - "по-видимому написано"
    - "архивный шифр"
forbidden_edits:
  - Нельзя менять датировки без источника — АБСОЛЮТНЫЙ ЗАПРЕТ
  - Нельзя переформулировать архивные шифры
  - Нельзя убирать оговорки при атрибуции
  - Нельзя заменять точные цитаты из рукописей пересказом
pipeline_risk: very_high
pipeline_risk_reason: "Идентично ИЭШ: любая правка дат или атрибуций без источника — научная ошибка"
```

### Кластер L4: Мифопоэтическая школа

**Ключевые фигуры:** Мелетинский, Неклюдов, частично Топоров  
**Связь с лингвистикой:** `cluster:mts` — литературоведческое крыло

**Стилистические маркеры:**
- «Архетип», «мифологема», «сюжетная инвариантность» — термины, не метафоры
- Широкие межкультурные параллели допустимы как аргументы
- Нарративный инвариант выявляется через сравнение вариантов
- Ссылки на Проппа, Леви-Стросса, Юнга — в зависимости от поколения автора
- Перечислительный стиль: «ср. также», «аналогично в», «то же самое в»

**Норма неопределенности:** средне-высокая. Гипотетические реконструкции допустимы.

```yaml
id: cluster:lit_mythopoetics
name: "Мифопоэтическая школа"
extends: cluster:mts
markers:
  lexical:
    - "архетип"
    - "мифологема"
    - "инвариант сюжета"
    - "медиатор"               # термин Леви-Стросса
    - "бинарная оппозиция"
forbidden_edits:
  - Нельзя убирать межкультурные параллели как «не относящиеся к делу»
  - Нельзя заменять «мифологема» на «образ»
  - Нельзя сокращать перечисления параллелей
pipeline_risk: medium_to_high
```

### Кластер L5: Нарратологическая школа

**Ключевые фигуры:** Женетт (в переводах), Шмид, Падучева (на стыке с лингвистикой), Тюпа  
**Характер:** Наиболее формализованная из литературоведческих школ после структурной

**Стилистические маркеры:**
- Строгая система терминов: нарратор/имплицитный автор/фокализатор/актор — не взаимозаменяемы
- Схемы нарративных уровней — аргументы
- Различение «истории» и «дискурса» / «фабулы» и «сюжета» — принципиально
- Анализ ведется через категории, а не через тематику

**Норма неопределенности:** низкая. Категории точны.

```yaml
id: cluster:lit_narratology
name: "Нарратологическая школа"
markers:
  lexical:
    - "нарратор"
    - "фокализатор / фокализация"
    - "имплицитный автор"
    - "диегезис"
    - "фабула / сюжет"          # различение принципиально
    - "несобственно-прямая речь"
  epistemic:
    - category_precision: high
    - anti_impressionism: true
forbidden_edits:
  - Нельзя заменять «нарратор» на «автор» — это разные инстанции
  - Нельзя путать «фабулу» и «сюжет»
  - Нельзя убирать термин «фокализация»
pipeline_risk: medium
```

### Кластер L6: Диалогическая / Бахтинская школа

**Ключевые фигуры:** Бахтин, Волошинов, Медведев, современные бахтинисты  
**Особенность:** Намеренная терминологическая нестрогость как философская позиция  
**Предупреждение:** Это самый трудный кластер для LLM — соблазн «причесать» очень высок

**Стилистические маркеры:**
- «Диалог», «полифония», «хронотоп», «карнавал» — авторские термины Бахтина; нельзя заменять
- Длинные периоды с несколькими встроенными мыслями — намеренно
- Эссеистичность допустима; четкие дефиниции сознательно избегаются
- «Большое время», «голос», «слово» — термины с особым значением, отличным от обыденного
- Бахтин рассуждает, а не доказывает — это не дефект, а жанр

**Норма неопределенности:** очень высокая. Открытость — принцип.

**Конфликты:** Прямо конфликтует с L1 (ОПОЯЗ: антипсихологизм vs. диалог субъектов) и с L5 (нарратология: строгие категории vs. открытые понятия).

```yaml
id: cluster:lit_bakhtin
name: "Диалогическая / Бахтинская школа"
markers:
  lexical:
    - "полифония"
    - "хронотоп"
    - "карнавал / карнавализация"
    - "диалог / диалогизм"
    - "большое время"
    - "чужое слово"
    - "двуголосое слово"
  syntactic:
    - essayistic_style_acceptable: true
    - long_meditative_periods: true
    - definition_avoidance: intentional
  epistemic:
    - openness_as_principle: true
    - anti_finalization: true      # Бахтин против «завершенности» — в т.ч. в стиле

pipeline_risk: very_high
pipeline_risk_reason: >
  LLM склонна «формализовать» Бахтина — добавлять четкие определения,
  разбивать периоды, заменять «диалог» на «взаимодействие».
  Всё это уничтожает авторскую позицию.
  Рекомендуемый режим: comments_only. Revision запрещена без явного разрешения.

forbidden_edits:
  - Нельзя определять «хронотоп» — Бахтин не давал жесткого определения намеренно
  - Нельзя заменять «голос» на «точку зрения» — разные концепты
  - Нельзя разбивать медитативные периоды
  - Нельзя добавлять «то есть» с разъяснением авторских терминов
  - Нельзя «исправлять» эссеистичность на академичность

conflict_resolution:
  vs_lit_opoyaz: escalate_with_note  # «парадигматический конфликт, решение за автором»
  vs_lit_narratology: escalate
  vs_nss: bakhtin_wins
```

### Кластер L7: Историко-культурная и компаративная школа

**Ключевые фигуры:** Аверинцев, Гаспаров М.Л., Жирмунский, Веселовский (как основа)  
**Характер:** Широкая эрудиция как инструмент; компаративный метод; исторический контекст обязателен

**Аверинцев** заслуживает отдельного замечания: его стиль — редкое сочетание академической строгости и писательского мастерства. Это частный случай внутри кластера.

**Стилистические маркеры:**
- Исторический контекст всегда присутствует как рамка интерпретации
- Компаративные параллели из нескольких литератур — аргументы
- Ссылки в сносках развернуты (не «ср. X», а полные координаты источника)
- Допустима культурологическая эссеистичность (особенно Аверинцев)
- «Эпоха», «культурный тип», «жанровая память» — термины

**Норма неопределенности:** средняя. Интерпретация допустима при историческом обосновании.

```yaml
id: cluster:lit_historico_cultural
name: "Историко-культурная и компаративная школа"
key_sub_styles:
  - private:averintsev           # особый идиолект внутри кластера
  - private:gasparov_ml
markers:
  lexical:
    - "историко-культурный контекст"
    - "жанровая традиция"
    - "культурный тип"
    - "компаративный анализ"
  epistemic:
    - historical_frame_required: true
    - wide_erudition_as_method: true
forbidden_edits:
  - Нельзя убирать исторические экскурсы как «не относящиеся к теме»
  - Нельзя сокращать сноски — они часть аргументации
pipeline_risk: medium
```

### Кластер L8: Рецептивная эстетика и теория читателя

**Ключевые фигуры:** Изер, Яусс (переводы); российские исследователи: Тюпа, Барт (переводной)  
**Характер:** Интерпретация текста через акт чтения; рецепция как объект

**Стилистические маркеры:**
- «Имплицитный читатель», «горизонт ожиданий» — термины, не метафоры
- Анализ динамики чтения (не статической структуры текста)
- Допустима феноменологическая риторика
- «Стратегия текста», «эффект» — частые

```yaml
id: cluster:lit_reception
name: "Рецептивная эстетика и теория читателя"
markers:
  lexical:
    - "имплицитный читатель"
    - "горизонт ожиданий"
    - "рецепция"
    - "стратегия текста"
    - "эстетический эффект"
  epistemic:
    - reader_as_co_author: true
    - dynamic_analysis_preferred: true
forbidden_edits:
  - Нельзя заменять «горизонт ожиданий» на «читательские ожидания»

```

### Кластер L9: Постструктуралистская и деконструктивистская критика

**Ключевые фигуры:** Деррида, Барт (переводной), Кристева (переводной); российские последователи  
**Предупреждение:** Кластер намеренно нарушает правила дискурса — LLM будет склонна «исправлять» это

**Стилистические маркеры:**
- Игровая, само-рефлексивная риторика
- Неологизмы и авторские термины (différance, след, письмо)
- Цитаты используются как объекты деконструкции, а не как поддержка тезиса
- Границы жанра (статья / эссе / философский текст) намеренно размыты
- «Центр», «присутствие», «логоцентризм» — термины с очень специфическим значением

**Норма неопределенности:** максимальная по принципу.

```yaml
id: cluster:lit_poststructural
name: "Постструктуралистская и деконструктивистская критика"
markers:
  lexical:
    - "деконструкция"
    - "след"                    # не след ноги — философский термин
    - "différance"              # авторское написание Деррида, не опечатка
    - "письмо"                  # не процесс, а концепт
    - "логоцентризм"
  epistemic:
    - genre_boundary_blurring: intentional
    - neologisms_as_tools: true
    - self_referential_style: intentional

pipeline_risk: very_high
pipeline_risk_reason: >
  LLM будет «исправлять» différance на différence, убирать игровую риторику,
  добавлять четкие дефиниции, упрощать синтаксис.
  Всё это противоположно авторскому намерению.
  Рекомендуемый режим: read_only / comments_only строго.

forbidden_edits:
  - Нельзя исправлять différance — это намеренное написание
  - Нельзя добавлять дефиниции авторских терминов
  - Нельзя «упрощать» стиль
  - Нельзя убирать само-рефлексивные комментарии
```

## Часть II. Обобщенный опыт литературоведческого корпуса

**Закономерность L1: Школа задает онтологию, а не только стиль.**  
Для формалиста текст — механизм. Для Бахтина — голос. Для нарратолога — структура. LLM-правка, которая «правильна» в одной онтологии, разрушительна в другой. Pipeline должен определять онтологию до применения любых правок.

**Закономерность L2: Авторские термины в литературоведении — не жаргон.**  
«Остранение», «хронотоп», «différance», «мифологема» — это технические термины с точными определениями внутри школы. Замена на «обычные слова» — не упрощение, а уничтожение смысла.

**Закономерность L3: Эссеистичность — это жанр, а не дефект.**  
Аверинцев, Бахтин, поздний Лотман пишут в жанре ученого эссе. Требование «четких дефиниций» и «академического синтаксиса» для этих текстов неприменимо.

**Закономерность L4: Цитата выполняет разные функции в разных кластерах.**  
В L3 (текстология) — доказательство. В L6 (Бахтин) — объект анализа. В L9 (деконструкция) — мишень деконструкции. Правило «сокращай длинные цитаты» не универсально.

**Закономерность L5: Литературоведение работает с интерпретацией как нормой.**  
В отличие от лингвистики, здесь нет «неверных» фактов в том же смысле. Верификация для pipeline выглядит иначе: не «правда ли это», а «обоснована ли интерпретация в рамках данной школы».
