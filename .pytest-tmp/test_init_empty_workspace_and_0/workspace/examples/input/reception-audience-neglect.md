# Игнорирование роли читателя

В статье утверждается: «Значение романа *Улисс* является объективным фактом, заложенным Джойсом в структуру текста раз и навсегда. Читатель лишь пассивно воспринимает этот готовый смысл, не привнося ничего своего».

Ожидаемая реакция Рецептивной эстетики:
1. Опровержение: значение рождается в акте чтения (горизонт ожидания).
2. Пометка о том, что текст — это партитура, которую исполняет читатель.
3. Упоминание «имплицитного читателя».
