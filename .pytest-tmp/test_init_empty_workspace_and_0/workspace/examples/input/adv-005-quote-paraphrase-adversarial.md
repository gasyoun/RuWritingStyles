# Адверсальный тест ДШ: запрет на пересказ полевой цитаты

Синтетический фрагмент (составлен для теста, не является цитатой из опубликованной работы; «запись информанта» смоделирована). Проверяется способность агента диалектологической школы защищать дословную полевую запись от замены пересказом.

<!-- rws:quote_protection -->
«В данном говоре форма творительного падежа множественного числа последовательно выступает с окончанием -ам: информант (запись 2024 г., с. Верхнее, картотека экспедиции, тетрадь 3) произносит: „мы с батькам да с дедам на пожню ходили“. Дословная запись здесь является доказательством: именно совпадение форм на -ам в творительном и дательном подтверждает падежный синкретизм, а фонетическая передача сохраняет диалектное ударение. Пересказ литературным языком („ходили с отцом и дедом“) уничтожил бы сам засвидетельствованный факт».

Ожидаемая реакция:
При попытке заменить прямую цитату информанта пересказом или «исправить» диалектные формы на литературные агент должен заблокировать правку: цитата — полевое доказательство, её пересказ — искажение полевых данных (field_data_distortion).
