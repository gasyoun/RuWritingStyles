# Phase 1 worked example — full pipeline run

_Created: 02-09-2026 · Last updated: 02-09-2026_

Roadmap unit ["Прогнать статью"](https://github.com/gasyoun/RuWritingStyles/blob/main/docs/roadmap-sanskrit-dh.md)
(Ф1, H3780 triage) asked for a working example of the full pipeline —
`prepare → review → council → revise → verify → report` — over the council
named in the roadmap text (Зализняк-очерк + Казанский + Лидова +
Tronsky-Readings), fixed on a non-sensitive fragment and committed under
`examples/`. This directory is that artifact.

## Reproduce

```powershell
$env:PYTHONPATH='src'
python -m ruwritingstyles.cli run examples/input/article-snippet.md `
  --run-id phase1-council-example `
  --styles zalizniak-ocherk,kazanskiy-korpus,lidova-commentary,tronsky-readings `
  --journal vya --execute --provider mock
python -m ruwritingstyles.cli validate-run runs/phase1-council-example
```

`--provider mock` is deliberate — the same choice
[case-study-phase1.md](https://github.com/gasyoun/RuWritingStyles/blob/main/docs/case-study-phase1.md)
made: content-level council advice needs a paid provider (author decision, still
open per the GTD row), but the **deterministic layer** — transliteration
linting, GOST bibliography, citation grounding, `report.tex`/`references.bib`
generation, journal-profile checks — runs for real regardless of provider and
is what this example exercises end to end.

## Source fragment

[`examples/input/article-snippet.md`](https://github.com/gasyoun/RuWritingStyles/blob/main/examples/input/article-snippet.md)
— a public, non-sensitive excerpt (abstract + opening paragraph) of «Комментаторские
стратегии русских переводчиков санскритского эпоса», the same manuscript
[case-study-phase1.md](https://github.com/gasyoun/RuWritingStyles/blob/main/docs/case-study-phase1.md)
measured against; the full unpublished draft stays in the private
`RuWritingStyles-corpus` sibling.

## What's here

- `original.md` / `revised.md` / `revision.diff` — the segment before and after
  council revision.
- `council.json` — the four styles' review + council deliberation record.
- `verification.json`, `translit-lint.json`, `citations.json` — the
  deterministic checks (transliteration linter: 0 findings; citations: 4/4
  verified against `knowledge/bibliography.json`).
- `report.md` / `report.tex` — the assembled report, including the LaTeX
  `\bibitem` block.
- `references.bib` / `references-gost.md` — the BibTeX and ГОСТ Р
  7.0.100-2018 short-form bibliography, generated by
  [`gost.py`](https://github.com/gasyoun/RuWritingStyles/blob/main/src/ruwritingstyles/gost.py)/[`bibtex.py`](https://github.com/gasyoun/RuWritingStyles/blob/main/src/ruwritingstyles/bibtex.py).

Prompts, per-provider logs, and other run-internal scratch (`runs/` proper) are
gitignored and not duplicated here — this directory is a curated snapshot of
the artifacts, not the live run.
