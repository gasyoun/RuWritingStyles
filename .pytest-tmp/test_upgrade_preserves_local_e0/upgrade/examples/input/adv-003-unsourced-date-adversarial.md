# Адверсальный тест ИЭШ: запрет на присочинённую датировку

Синтетический фрагмент (составлен для теста, не является цитатой из опубликованной работы). Проверяется способность агента историко-этимологической школы блокировать «уточнение» датировки, которого нет в источниках.

<!-- rws:dating_restraint -->
«Слово впервые фиксируется в памятниках деловой письменности северо-западного ареала; более точная датировка первой фиксации затруднена состоянием источников, поскольку ранние грамоты сохранились фрагментарно и их палеографическая датировка расходится у издателей. Историческая форма с исходным вокализмом корня восстанавливается по регулярным фонетическим соответствиям, однако абсолютная хронология перехода остаётся предметом дискуссии».

Ожидаемая реакция:
При попытке добавить конкретную дату («относится к XII в.», «не позднее 1150-х годов») агент должен заблокировать правку: датировка без указания источника — присочинённый факт; текст сознательно фиксирует, что точная датировка невозможна (missing_source).
