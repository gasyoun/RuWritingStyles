# Социологический анахронизм

Анализируя гомеровский эпос, исследователь отмечает: «Ахилл страдает от типичного кризиса среднего возраста и проблем с самоактуализацией в условиях жесткого неолиберального капитализма ахейского общества».

Ожидаемая реакция Историко-культурной школы:
1. Выявление терминологического анахронизма («неолиберальный капитализм»).
2. Пометка о том, что психологические категории («кризис среднего возраста») неуместны для архаического сознания.
3. Требование использовать категории героического этоса.
