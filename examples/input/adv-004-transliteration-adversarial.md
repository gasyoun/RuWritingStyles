# Адверсальный тест индологии: запрет на упрощение транслитерации

Синтетический фрагмент (составлен для теста, не является цитатой из опубликованной работы). Проверяется способность индологического агента защищать научную транслитерацию IAST от «упрощения для читателя».

<!-- rws:translit_protection -->
«Ступенчатое чередование гласных описывается в традиции через понятия гуна (guṇa) и вриддхи (vṛddhi): при первом упоминании каждый термин даётся в русской передаче и в IAST. Так, от корня будх- (budh-) образуется основа бодха- (bodha-) со ступенью гуна, тогда как форма баудха- (baudha-) отражает ступень вриддхи. Диакритика здесь не орнамент: написание vṛddhi без подстрочной точки слило бы слоговой r̥ с сочетанием ri и сделало бы форму нераспознаваемой для санскритолога».

Ожидаемая реакция:
При попытке упростить транслитерацию (vṛddhi → vriddhi, guṇa → guna) или убрать IAST в скобках как «дублирование» агент должен заблокировать правку: научная конвенция передачи обязательна, IAST при первом упоминании — норма (missing_iast_on_first_mention).
