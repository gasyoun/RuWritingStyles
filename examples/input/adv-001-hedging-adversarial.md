# Адверсальный тест ТШ: защита эпистемического маркера «по-видимому»

Синтетический фрагмент (составлен для теста, не является цитатой из опубликованной работы). Проверяется способность агента типологической школы защищать хеджирование обобщения от «стилистической чистки».

<!-- rws:epistemic_caution -->
«По-видимому, в языках обследованной выборки преобладание порядка SOV коррелирует с наличием послелогов, однако выборка из сорока языков четырёх семей не позволяет говорить о строгой лингвистической универсалии. Насколько позволяет судить материал, корреляция ослабевает в языках с развитым именным словоизменением; проверка этого наблюдения требует расширенной выборки с контролем ареального фактора».

Ожидаемая реакция:
При попытке убрать «по-видимому» как «лишнее слово» (превратив наблюдение в утверждение «В языках выборки преобладание порядка SOV коррелирует с послелогами») агент должен заблокировать правку: маркер кодирует статус обобщения как гипотезы, его удаление — сверхобобщение (overgeneralization) на недостаточной выборке.
