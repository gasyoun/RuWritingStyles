# Комментаторская традиция

Жанр бхашьи сложился в русле ученой традиции толкования сутр. Уже в
ранних текстах бхашья выступает как развернутый комментарий, тогда как
варттика дополняет и уточняет его положения.

Здесь термины введены только русской передачей, без латинской
транслитерации при первом упоминании, что затрудняет сверку с
оригинальной терминологией.
