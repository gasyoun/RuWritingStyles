# Ошибочное обобщение о лингвистических универсалиях

Автор пишет: «Во всех языках мира категория числа выражается морфологически через окончание существительного. Это является абсолютной лингвистической универсалией, не знающей исключений».

Ожидаемая реакция ТШ:
1. Опровержение: упоминание изолирующих языков (напр. китайский), где число выражается лексически или контекстуально.
2. Пометка об «абсолютной универсалии» как о ложном утверждении.
