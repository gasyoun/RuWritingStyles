- **Anthropic provider default model bumped off a retired ID (H5352, Claude Code Opus 5 `claude-opus-5`, 24-09-2026):** [`AnthropicProvider.effective_model`](https://github.com/gasyoun/RuWritingStyles/blob/main/src/ruwritingstyles/providers.py) fell back to `claude-3-5-sonnet-20240620`, retired on 28-10-2025 — every run without `RWS_ANTHROPIC_MODEL` set was getting a 404 from the fallback path. Default is now `claude-sonnet-5`. No test pinned the old default (grepped), and the request body the provider builds carries no `temperature`/`top_p`/`top_k`, so the bump is safe on Sonnet 5, which rejects those with a 400. `RWS_ANTHROPIC_MAX_TOKENS` (default 8192) is unchanged; note that on Sonnet 5 adaptive thinking is on by default and its tokens count toward that cap. Source: [claude-config PROMPT_AUDIT_INSTRUCTION_ESTATE_AND_API_CODE_23-09-2026.md](https://github.com/gasyoun/claude-config/blob/main/docs/PROMPT_AUDIT_INSTRUCTION_ESTATE_AND_API_CODE_23-09-2026.md) hunk F3.
